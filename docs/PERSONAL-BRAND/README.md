# Farouk Pandor Personal Brand Hub

## Strategic role

This repository is being repositioned as the canonical **Farouk Pandor Professional & Enterprise Portfolio Hub**.

It is the human/professional layer connecting:

**Person → Credentials → Experience → Evidence → Knowledge → Projects → Enterprises → Digital Assets → Opportunities**

It is not itself another operating enterprise.

## Deployment principle

Primary public deployment target:

**GitHub Pages — `https://faroukpandor.github.io/`**

GitHub's user-site convention requires a repository named `faroukpandor.github.io`. The existing `faroukpandor` repository remains the historical/source repository until the migration strategy is approved and implemented.

The site must remain provider-portable so the same static output can also be deployed to Cloudflare Pages or another compatible static host.

## Current repository archaeology

The existing repository is based on the deprecated Victor Hugo boilerplate and currently uses an old Hugo/Webpack/Node/Sass dependency stack. The repository contains useful Farouk-specific material, including the 2025 "Strategy for Monetizing Passions" content, but also retains upstream/template material.

Therefore:

**Preserve useful content/history → classify it → replace obsolete infrastructure deliberately → build the new public interface.**

Do not perform a blind dependency upgrade or wholesale deletion.

## Evidence and ownership rule

Every public portfolio claim should be classified as appropriate:

- VERIFIED
- DOCUMENTED
- SELF-REPORTED
- HISTORICAL
- UNVERIFIED
- REQUIRES CONFIRMATION

Historical concepts must not automatically be presented as current enterprises.

Client/third-party assets must not be presented as Farouk-owned.

## Design objective

The public interface must be premium, distinctive, fast, accessible and evidence-driven.

Target experience:

**high-end editorial + enterprise intelligence + modern digital product**

Avoid generic portfolio/SaaS aesthetics, excessive gradients, gratuitous glassmorphism, visual clutter and template-like layouts.

## Execution gate

Do not make the website visually complex before the underlying professional record, asset ledger, ownership/status register and enterprise routing model are sufficiently established.
