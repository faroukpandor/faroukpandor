# Enterprise Routing Matrix

## Principle

The personal hub is a routing layer, not a replacement for specialist enterprise sites.

**Visitor need → Capability → Evidence → Canonical enterprise → Offer → Action**

## Routing decision

Before creating a new enterprise or repository:

1. Does an existing capability already solve the need?
2. Does a canonical enterprise already own the capability?
3. Does an existing repository already contain the implementation?
4. Can the opportunity become a feature, service, product, research asset or content asset?
5. Only if none of these apply should a new enterprise/repository be considered.

## Regulated-service boundary

Where a service requires a licensed/registered professional, the personal hub may describe coordination/orchestration capabilities but must not imply that Farouk personally performs regulated professional acts without evidence of authorization.

## Commercial routing

The personal hub should generate qualified routing rather than duplicate enterprise checkout systems.
