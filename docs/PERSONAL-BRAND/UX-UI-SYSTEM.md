# Premium UX/UI System

## Product character

The Farouk Pandor hub should feel like a **professional intelligence and enterprise portfolio platform**, not a conventional résumé website.

Desired qualities:

- premium
- precise
- intelligent
- calm
- distinctive
- credible
- editorial
- globally professional
- contextually grounded in Botswana/Africa without relying on stereotypes

## Core experience

The visitor should quickly understand:

1. Who Farouk is.
2. What capabilities he brings.
3. What evidence exists.
4. Which projects demonstrate those capabilities.
5. Which enterprise owns or operates each capability.
6. What action is appropriate next.

## Information hierarchy

**Farouk Pandor**
→ Professional identity
→ Capabilities
→ Evidence
→ Projects
→ Canonical enterprises
→ Digital assets
→ Opportunities

## Signature interaction

Develop an accessible portfolio relationship view:

**Person → Capability → Evidence → Project → Enterprise → Opportunity**

This may be visualised interactively on capable devices but must have an equally clear accessible list/card representation.

## Visual direction

Use a sophisticated design system with:

- exceptional typography
- deliberate spacing
- strong grid
- restrained colour system
- high-quality responsive cards
- editorial composition
- subtle depth
- elegant dividers
- carefully controlled motion
- meaningful status/provenance indicators

Avoid:

- excessive gradients
- generic glassmorphism
- neon AI styling
- excessive rounded cards
- stock-photo dependence
- animation everywhere
- decorative elements without information value

## Motion

Motion should communicate state, hierarchy or continuity.

Required:

- reduced-motion support
- short transitions
- accessible focus states
- no blocking animation
- no interaction dependent solely on animation

## Mobile

Mobile is a first-class experience.

Requirements:

- thumb-friendly controls
- readable typography
- no horizontal overflow
- simplified navigation
- touch-friendly filtering
- fast loading on constrained networks
- accessible expandable content

## Accessibility

Implement:

- semantic HTML
- keyboard navigation
- visible focus
- logical heading structure
- meaningful alternative text
- sufficient contrast
- reduced-motion support
- accessible forms
- screen-reader-compatible navigation

## Performance

Prefer:

- static HTML
- minimal JavaScript
- optimised images
- lazy loading
- limited dependencies
- progressive enhancement
- caching
- CDN delivery

The premium experience must not depend on heavy client-side rendering.

## Design-system components

Build reusable components for:

- navigation
- hero
- section headers
- capability cards
- evidence cards
- enterprise cards
- project cards
- timeline
- portfolio map
- status badges
- provenance indicators
- CTAs
- contact
- footer

## Quality principle

**Extraordinary interface around extraordinary evidence.**

Visual sophistication must never be used to conceal weak evidence, unsupported claims or unclear ownership.
